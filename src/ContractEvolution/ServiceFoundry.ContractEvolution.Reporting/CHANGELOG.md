## [0.1.0] — 2026-05-21

### Added
- `ContractEvolutionTextReportWriter` — human-readable plain-text report of all contract families, versions, and edges.
- `ContractEvolutionJsonReportWriter` — structured JSON report suitable for dashboards, CI artefacts, or API responses.
- `ContractFamilyReport`, `ContractVersionReport`, and `ContractEdgeReport` DTOs.
